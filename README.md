# Страницы приложения «Рассвет»

Политика приватности и поддержка — то, что требуют Play Console и App Store Connect:

- [Политика приватности](https://muren2000.github.io/rassvet-site/privacy/)
- [Поддержка](https://muren2000.github.io/rassvet-site/support/)

**Репозиторий сгенерирован — править его вручную бесполезно.** Содержимое собирается
из приватного репозитория приложения (`scripts/build-site.ts`, текст политики —
`src/data/privacy.ts`, общий с экраном «Приватность») и перезаписывается целиком
при каждой публикации.

Нашли ошибку в тексте? Она правится в приложении — напишите через
[страницу поддержки](https://muren2000.github.io/rassvet-site/support/).
